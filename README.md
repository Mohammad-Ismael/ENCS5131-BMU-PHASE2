# ENCS5131-BMU-PHASE2

The **Bit Manipulation Unit (BMU)** is a high-performance execution coprocessor/ALU sub-block designed for RV32 processor cores. It accelerates bit-level transformations, cryptography primitives, bit-field extraction/insertion, address calculations, and data packing.

Checkout the BMU specs [BMU_Phase2_Specification.md](BMU_Phase2_Specification.md) and your assignment [BMU_Phase2_Project_Assignment.md](BMU_Phase2_Project_Assignment.md).
